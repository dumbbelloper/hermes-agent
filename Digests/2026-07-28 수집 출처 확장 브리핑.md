## 운영 결과

기존 4개 출처에 공식 RSS·Atom, JSON 또는 쉽게 파싱 가능한 정적 HTML 5개를 추가해 운영 Registry를 9개로 확장했다. 두 차례 실제 수집에서 모두 9/9 성공했으며, 현재 누적 레코드는 1,544건이고 격리된 레코드는 없다. 두 번째 실행에서는 전 레코드가 `unchanged`로 판정돼 반복 수집 멱등성을 확인했다.

새로 운영하는 채널은 Visa Developer Release Notes, Visa Acceptance Devices iOS SDK Releases, American Express Newsroom, UnionPay Company News와 UnionPay Market News다. 세부 URI와 판정 근거는 [수집 출처 운영 분류](../SOURCE_CATALOG.md)에서 확인할 수 있다.

## 제외·보류

- Mastercard Newsroom은 Akamai 403이 유지돼 제외한다.
- Mastercard·American Express Developer Portal은 일반 HTTP에서 JavaScript 셸만 제공하므로 제외한다.
- Visa Use Cases는 정적 수집이 쉽지만 게시일이 없어 현재 공통 레코드 계약에 넣지 않는다.
- UnionPay Media Reports와 Statements는 JSON이 존재하지만 각각 외부 기사 재게시 성격·장기 정체 때문에 제외한다.
- EMVCo Specifications와 PCI SSC Document Library는 접근 가능하지만 항목별 버전·수정일 parser가 없어 후보로 유지한다.
- Visa의 나머지 선별 GitHub 저장소는 release feed가 비어 있거나 2022년 이후 정체돼 운영 Registry에 넣지 않는다.
